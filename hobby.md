# Мой пет-проект

Идея: Telegram-бот для учёта личных расходов — пишешь «кофе 250», бот сохраняет трату и по команде /stats показывает сумму по категориям за месяц.

Стек: Python (aiogram) + SQLite, позже — Docker и деплой на VPS.

Цель: научиться писать и деплоить небольшой сервис целиком — от кода до автоматической выкладки через CI/CD.

## Сроки реализации
1. Неделя 1–2 — MVP: бот принимает траты командой «категория сумма».
2. Неделя 3 — хранение в SQLite и команда /stats за месяц.
3. Неделя 4 — упаковка в Docker.
4. Неделя 5 — CI/CD на GitHub Actions и деплой на VPS.
