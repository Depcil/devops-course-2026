# Git в VS Code и в терминале

## Что удобно делать в VS Code
1. Смотреть diff: панель Source Control показывает изменения бок о бок, сразу видно, какие строки добавлены и удалены.
2. Индексировать изменения выборочно — кнопкой «+» у файла или даже отдельного фрагмента (Stage Selected Ranges) вместо `git add -p`.
3. Видеть авторство строк: GitLens показывает прямо в редакторе, кто и в каком коммите менял строку (визуальный `git blame`), и историю файла.

## Что удобнее делать в терминале
- Сложные операции с историей — `git rebase -i`, `cherry-pick`, `reflog`, а также работа на сервере по SSH, где IDE нет вообще.
