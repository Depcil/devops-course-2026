# Мои цели на семестр

1. Уверенно работать с Git в терминале: ветки, Pull Request, rebase, разрешение конфликтов.
2. Научиться упаковывать приложения в Docker-контейнеры и запускать их через Docker Compose.
3. Настроить собственный CI/CD-пайплайн на GitHub Actions, который проверяет и деплоит проект.
